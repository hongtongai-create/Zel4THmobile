# Zel4THmobile — คู่มือใช้งานฉบับละเอียด

คู่มือนี้พาไปตั้งแต่ติดตั้งครั้งแรกจนถึงใช้งานจริงทุกส่วนของบอร์ด: สร้าง agent, คุยกับ agent,
ให้ agent คุมเครื่องอื่น, สร้างภาพ/วิดีโอ, และแต่งฉาก/ตัวละครในสตูดิโอ
ถ้าต้องการดูตัวแปร env ทั้งหมดให้เปิด `.env.example` ประกอบ

---

## 1. ภาพรวมใน 30 วินาที

Zel4THmobile คือ **agent harness** ที่มีสองส่วน:

| ส่วน | หน้าที่ |
|---|---|
| **gateway** (Node process) | ถือ token, รับ-ส่ง WebSocket กับบอร์ด, เรียกโมเดล, รัน tool, เก็บข้อมูลใน `data/` |
| **board** (เว็บแอพ `/`) | หน้าจอควบคุมบนมือถือ/เดสก์ท็อป คุยกับ agent เห็นตัวละครเดินในฉาก |

ทุกอย่างที่คุณแก้ในบอร์ด (agent, เครื่อง, ฉาก, ธีม) ถูกบันทึกเป็นไฟล์ข้อมูล ไม่ใช่โค้ด
จึงไม่ต้องรีสตาร์ทและไม่ต้องเขียนโปรแกรมใหม่

```
มือถือ/เบราว์เซอร์  ──WebSocket + token──►  gateway  ──►  model API
        │                                     │
        └── ไฟล์ใน data/ และ board/assets/ ◄──┘
```

## 2. ติดตั้งและเปิดครั้งแรก

ต้องมี **Node.js 20 ขึ้นไป**

```bash
git clone https://github.com/hongtongai-create/Zel4THmobile.git
cd Zel4THmobile
npm install

cp .env.example .env
```

แก้ `.env` อย่างน้อยสามค่า:

```bash
GATEWAY_TOKEN=สุ่มยาว ๆ                # openssl rand -hex 32
OPENAI_API_KEY=...                     # หรือ provider อื่น (หัวข้อ 6)
PORT=8787
HOST=127.0.0.1                         # ใช้ในวงเดียวกัน; ถ้าจะเปิดให้เครื่องอื่นใช้ 0.0.0.0
```

> `GATEWAY_TOKEN` คือรหัสเดียวที่กันบอร์ดไว้ — ใครมี token นี้เท่ากับคุม agent ได้
> อย่าใส่ใน git และอย่าส่งในแชท

รัน:

```bash
npm run build        # ครั้งแรกครั้งเดียว (หรือหลังแก้โค้ด)
npm start            # = node dist/cli.js gateway
```

ระหว่างพัฒนาใช้ `npm run dev` (tsx, ไม่ต้อง build) ได้

> **npm 12 ขึ้นไป**: npm รุ่นใหม่บล็อก install script ของ dependency โดยค่าเริ่มต้น จึงอาจเห็น `npm warn install-scripts 1 package has install scripts not yet covered by allowScripts: esbuild`
> — ไม่ใช่ error และไม่กระทบ `npm start` (รันไฟล์ที่ compile แล้ว) รีโปนี้ประกาศ `"allowScripts": { "esbuild": true }` ไว้ใน `package.json` แล้ว
> ถ้าต้องการให้ `npm run dev` ทำงาน ให้อนุมัติ esbuild: `npm install-scripts approve esbuild` แล้ว `npm rebuild esbuild`

เปิดเบราว์เซอร์:

```
http://127.0.0.1:8787/?token=<GATEWAY_TOKEN>
```

ถ้าไม่มี token หรือ token ผิด จะได้ `401 unauthorized` — คัดลอก URL พร้อม `?token=` เก็บไว้ใช้ซ้ำ

## 3. ติดตั้งเป็นแอพบนมือถือ (PWA)

บอร์ดเป็น PWA ใช้ไอคอนเดียวกับโลโก้ Zel4THmobile

- **iPhone/iPad (Safari)**: เปิดบอร์ด → ปุ่ม Share → **Add to Home Screen** → ตั้งชื่อ `Zel4THmobile`
- **Android (Chrome)**: เปิดบอร์ด → เมนู ⋮ → **Install app** หรือกดปุ่ม **Install as app** ในบอร์ด
- **เดสก์ท็อป (Chrome/Edge)**: ไอคอนติดตั้งบนแถบ address bar

หลังติดตั้ง แอพจะเปิดเต็มจอ (standalone) และจำ token จาก URL ที่ใช้ตอนติดตั้ง
ถ้าเปลี่ยน token ภายหลัง ให้เปิด URL ใหม่พร้อม token แล้วติดตั้งซ้ำ/ล้างข้อมูลเว็บแอพนั้น

## 4. สร้าง agent ตัวแรก

1. เปิดบอร์ด → ปุ่ม **☰** (มุมซ้ายบน) → **＋ สร้าง Agent**
2. กรอกฟอร์ม:

| ช่อง | ใส่อะไร | ตัวอย่าง |
|---|---|---|
| **ชื่อ** | ชื่อที่โผล่บนหัวตัวละคร | `Nova` |
| **อีโมจิ** | ใช้เมื่อยังไม่เลือกรูปตัวละคร | `🛰️` |
| **บทบาท (ROLE)** | บรรทัดเดียว บอกว่าตัวนี้คือตำแหน่งอะไร | `Agency Director / Grand Strategist` |
| **คำนำหน้าตอบ (REPLY PREFIX)** | บังคับคำขึ้นต้นเมื่อตอบคุณโดยตรง (ไม่ใช้ตอน agent คุยกันเอง) | `เคบ๊บ..บอส!! ☄️` |
| **ตัวตน / บุคลิก (IDENTITY)** | หลายบรรทัด: หน้าที่ กติกา วิธีพูด สิ่งที่ห้ามทำ | `คุณคือ Nova ... ตอบสั้น ตรงประเด็น ...` |
| **โมเดล** | เลือกจากรายการที่ตั้งค่าไว้ (ว่าง = ใช้ค่าเริ่มต้น) | `openai:gpt-4.1-mini` |
| **สี** | สีประจำตัว (ขอบ avatar, ชื่อ) | `#6ee7b7` |
| **ตัวละคร** | รูป/sprite จากสตูดิโอ | `Sirius` |
| **ให้ agent ทำอะไรได้บ้าง** | **ติ๊ก = อนุญาต** (ไม่ติ๊ก = ห้ามใช้ tool นั้น) | ติ๊ก `mac_run`, `image_generate` |
| **PLUGINS** | เปิด/ปิดปลั๊กอินทั้งชุด (เช่น ปลั๊กอินเครื่อง `s23-shell`) | ติ๊กเมื่อจะให้ใช้เครื่องนั้น |

3. กด **บันทึก** → ตัวละครโผล่ในฉากทันที

> เคล็ดลับ: แยก **ROLE** (ตำแหน่ง สั้น ๆ) ออกจาก **IDENTITY** (พฤติกรรมยาว ๆ)
> และใส่ **REPLY PREFIX** เมื่ออยากให้ทุกคำตอบขึ้นต้นเหมือนกัน — agent จะทำตามทั้งตอนคุยเดี่ยว
> และตอนถูกเรียกผ่านช่องทางอื่น (Telegram/LINE) แต่จะไม่ใส่ prefix เวลาคุยกับ agent ตัวอื่น

ลบ agent: เปิดการ์ด agent → **ลบ agent** (ประวัติแชทของตัวนั้นจะถูกลบด้วย)

## 5. คุยกับ agent

- แตะตัวละครในฉาก หรือกด **เปิดแชท** ในการ์ด agent → เปิดหน้าต่างแชท
- พิมพ์แล้วส่งได้เลย ระหว่างที่ agent ทำงาน ตัวละครจะมีไฟแสดงสถานะ (working)
- **✕** มุมขวาบนปิดหน้าต่างแชทกลับไปดูฉาก
- **ล้างประวัติ** ในหน้าการ์ด agent = เริ่มบทสนทนาใหม่ (ความจำของ agent คือประวัติแชท)
- ปุ่ม **แชท** บนแถบบนเปิดรายการบทสนทนาทั้งหมด

ปรับขนาดตัวอักษรแชท/ตัวละครได้ที่ **🎨 ฉาก / ตัวละคร / ธีม** (หัวข้อ 8)

### 5.1 พูดคุยด้วยเสียง (speech to speech)

ในหน้าต่างแชทมีสองปุ่มเสียง:

| ปุ่ม | อยู่ตรงไหน | ทำอะไร |
|---|---|---|
| 🎤 **(mic)** | ข้างช่องพิมพ์ | กดหนึ่งครั้ง → พูด → พอหยุดพูด ระบบถอดเสียงเป็นข้อความแล้ว **ส่งให้ agent อัตโนมัติ** (กดซ้ำเพื่อยกเลิก) |
| 🔈 **(ลำโพง)** | หัวหน้าต่างแชท | เปิด/ปิดการ **อ่านคำตอบออกเสียง** — จำค่าไว้ในเครื่อง เปิดครั้งเดียวใช้ได้ตลอด |
| 🎧 **(โหมดคุยต่อเนื่อง)** | หัวหน้าต่างแชท | เปิดแล้วไม่ต้องกดอะไรอีก: ฟัง → ส่งเอง → อ่านคำตอบ → ฟังต่อ วนอัตโนมัติ |

ขั้นตอนใช้งาน:

1. เปิดหน้าต่างแชทของ agent → อนุญาตไมโครโฟนเมื่อเบราว์เซอร์ถาม (ครั้งแรกครั้งเดียว)
2. กด 🎤 แล้วพูดเป็นภาษาไทย ข้อความที่ถอดได้จะโผล่ในช่องพิมพ์ระหว่างพูด
3. หยุดพูด → ข้อความถูกส่งเอง → agent ตอบ → ถ้าเปิด 🔈 ไว้จะได้ยินเสียงอ่านคำตอบ
4. พูดตอบกลับได้ทันที = วงจรเสียงเต็มรูปแบบ (พูด → agent → เสียงตอบ)

สิ่งที่ควรรู้:

- การถอดเสียงใช้ engine ของเบราว์เซอร์ (Chrome/Edge ส่งไปประมวลผลออนไลน์, Safari/iOS ใช้ระบบของเครื่อง) — **ต้องมีเน็ต** ตอนพูด
- การอ่านออกเสียงใช้เสียงในเครื่อง (`speechSynthesis`) — ทำงานได้แม้ออฟไลน์ และจะเลือกเสียง **ภาษาไทย** ให้ก่อนถ้ามีติดตั้งไว้ (iOS: ตั้งค่า → การช่วยการเข้าถึง → เสียงพูด; Android: ตั้งค่า → ระบบ → การแปลงข้อความเป็นคำพูด)
- ภาษาที่ใช้ฟังมาจาก `<html lang>` ของบอร์ด (ตอนนี้ `th` → `th-TH`); ถ้าอยากพูดอังกฤษให้เปลี่ยน lang หรือบอกให้เพิ่มตัวเลือกภาษา
- ถ้าเบราว์เซอร์ไม่รองรับ ปุ่ม 🎤 จะถูกซ่อนและมีข้อความบอกเมื่อกด
- เสียงที่เล่นค้างอยู่จะหยุดเมื่อส่งข้อความใหม่หรือปิดหน้าต่างแชท
### 5.2 โหมดคุยต่อเนื่อง (hands-free)

กดปุ่ม **🎧** ที่หัวหน้าต่างแชทหนึ่งครั้ง แล้วคุยได้เลยโดยไม่ต้องแตะจอ:

```
ฟัง (mic ติดตลอด) → พูดจบประโยค → ส่งให้ agent อัตโนมัติ
      ↑                                      ↓
   ฟังต่อ  ←  อ่านคำตอบออกเสียงจนจบ  ←  agent ตอบ
```

- **ส่งเองเมื่อจบประโยค** — ผลลัพธ์สุดท้าย (final) จาก engine จะถูกส่งทันที ไม่ต้องกด send
- **หยุดฟังขณะ agent ทำงาน/อ่านเสียง** — กันเสียงตัวเองย้อนกลับเข้าไมค์ (echo)
- **กลับมาฟังเอง** เมื่อ agent ตอบจบ + อ่านออกเสียงจบ (ถ้าปิดลำโพงไว้ จะกลับมาฟังทันทีที่คำตอบเสร็จ)
- เปิดโหมดนี้จะเปิดลำโพงให้อัตโนมัติ (ปิดทีหลังได้ แต่จะไม่ต่อเนื่องเท่า)
- กดปุ่ม 🎤 ระหว่างโหมดนี้ = ออกจากโหมด; กด 🎧 ซ้ำก็ออกเช่นกัน
- ปิดหน้าต่างแชท/สลับไปหน้าฉาก = หยุดฟังทันที (เปิดแชทใหม่แล้วโหมดยังจำอยู่ จะเริ่มฟังให้เอง)
- ถ้าไม่ได้ยินเสียงติดกัน 3 รอบ ระบบจะปิดโหมดเองและบอกให้ตรวจสิทธิ์ไมโครโฟน (กันลูปฟังเปล่าไม่จบ)

#### กัน agent ตอบตัวเอง (echo guard)

ลำโพงดังออกไมค์แล้ว agent ได้ยินเสียงตัวเอง = วนตอบตัวเองไม่จบ ระบบกันไว้ 4 ชั้น:

1. **ปิดไมค์ทันทีที่เริ่มอ่านเสียง** — `speak()` สั่ง `stopListening()` ก่อนเล่นเสียงทุกครั้ง
2. **ช่วงเว้นเงียบหลังอ่านจบ 1.4 วินาที** (`ECHO_GUARD_MS`) — ลำโพง/บลูทูธมักดังต่ออีกนิดหลัง `onend`; ในช่วงนี้ผลลัพธ์แบบ interim จะถูกทิ้ง และ `handsfreeTick` จะเลื่อนเปิดไมค์ออกไป
3. **ตัวกรองข้อความคล้ายเสียงตัวเอง** — เทียบข้อความที่ได้ยินกับประโยคที่เพิ่งอ่าน ด้วย trigram overlap (ทำงานกับภาษาไทยที่ไม่เว้นวรรค); ถ้าซ้ำกัน ≥ 50% ถือว่าเป็นเสียงสะท้อน ทิ้งไม่ส่ง
4. **คนพูดทับชนะ** — ถ้าคุณเริ่มพูดระหว่างที่ agent กำลังอ่าน ระบบจะตัดเสียงอ่านทันทีและรับประโยคของคุณแทน

แม้มี 4 ชั้นนี้ การใช้ **หูฟัง/บลูทูธ** ยังเป็นวิธีที่ชัวร์ที่สุด (ตัดปัญหา acoustic echo ที่ต้นทาง) — โดยเฉพาะเมื่อเร่งเสียงเครื่องดังมาก

ข้อจำกัด: การตัดจบประโยคอาศัย engine ของเบราว์เซอร์ (จะส่งเมื่อได้ final result) — ถ้าพูดแล้วมีเสียงรบกวนมาก engine อาจรอไปเรื่อย ๆ จนกว่าจะได้ final; ยังไม่มีปุ่ม “หยุดฟังชั่วคราว” แยกต่างหาก (ใช้ 🎧 ปิด/เปิดแทน)
- ถ้าต้องการคุณภาพภาษาไทยที่ดีกว่านี้มาก ทางเลือกคือต่อ STT/TTS ฝั่งเซิร์ฟเวอร์ (Whisper / TTS API) ซึ่งยังไม่ได้ทำในรีลีสนี้

## 6. ตั้งค่าโมเดล (หลายผู้ให้บริการพร้อมกัน)

ใส่ key ของผู้ให้บริการอย่างน้อยหนึ่งตัวใน `.env` แล้วรีสตาร์ท:

```bash
OPENAI_API_KEY=sk-...
# OPENAI_BASE_URL=https://api.openai.com/v1
# OPENAI_MODELS=gpt-4.1-mini,gpt-4o

OPENROUTER_API_KEY=sk-or-...
# OPENROUTER_MODELS=anthropic/claude-sonnet-4,google/gemini-2.5-flash

# endpoint ที่เข้ากันได้กับ OpenAI (Groq, vLLM, Freebuff paid API, ...)
# LLM_LABEL=Groq
# LLM_BASE_URL=https://api.groq.com/openai/v1
# LLM_API_KEY=
# LLM_MODELS=llama-3.3-70b-versatile

# โมเดลโลคัลผ่าน Ollama
# OLLAMA_ENABLED=1
# OLLAMA_MODELS=llama3.1,qwen2.5:7b

# โมเดลที่เริ่ม session ใหม่
# DEFAULT_MODEL=openai:gpt-4.1-mini
```

ตรวจว่ารายการขึ้นแล้ว:

```bash
npm run models          # หรือ node dist/cli.js models
```

ค่าใช้จ่ายโดยประมาณ: ใส่ `MODEL_PRICES` (USD ต่อ 1M token รูปแบบ `input/output`) แล้วดูย้อนหลังด้วย `npm run usage`

## 7. ให้ agent คุมเครื่องอื่น (ไม่ต้องเขียนโค้ด)

1. เมนู **☰** → **🖥 เครื่องที่ agent เข้าถึงได้**
2. ใส่ **IP** ของเครื่องปลายทาง (เครื่องเดียวกันใน Tailscale/วง LAN เดียวกัน), port (ปกติ `22`), user
3. กด **บันทึกเครื่อง** → ระบบสร้างปลั๊กอิน 1 เครื่อง = 1 ปลั๊กอิน พร้อม tool:
   - `<ชื่อย่อ>_run` — สั่งคำสั่ง shell
   - `<ชื่อย่อ>_read` — อ่านไฟล์
   - `<ชื่อย่อ>_write` — เขียนไฟล์
   ชื่อย่อมาจาก IP เช่น `100.99.99.99` → `t100_99_99_99`
4. เปิดการ์ด agent → ในส่วน **ให้ agent ทำอะไรได้บ้าง** จะมีกลุ่มของเครื่องใหม่โผล่ขึ้นมาให้ **ติ๊กอนุญาต**
   (รายการอัปเดตเองทันที ไม่ต้องรีสตาร์ท) — มีปุ่ม **＋ เพิ่มเครื่อง / IP ใหม่** ในหน้านี้ด้วย
5. เตรียม ssh key ให้ gateway ปลายทางไว้ใจ (ครั้งเดียว):

```bash
# บนเครื่องที่รัน gateway
ssh-keygen -t ed25519 -N "" -f ~/.ssh/zel4thmobile_ed25519   # ถ้ายังไม่มี
cat ~/.ssh/zel4thmobile_ed25519.pub                            # คัดลอกไปต่อท้าย authorized_keys ของเครื่องปลายทาง
```

ทดสอบจากบอร์ด: เปิดแชทกับ agent แล้วสั่ง เช่น
*"รัน `uname -a` บนเครื่อง 100.99.99.99 ให้ดูหน่อย"*

ลบเครื่อง: การ์ดเครื่องนั้น → **ลบ** (โฟลเดอร์ปลั๊กอินถูกย้ายไป `extensions/plugins/.removed/`)

> ความปลอดภัย: ให้สิทธิ์เท่าที่จำเป็น เครื่องที่ agent เขียนไฟล์ได้ = เครื่องที่ agent แก้ของได้จริง

## 8. สตูดิโอ: ฉาก / ตัวละคร / เฟอนิเจอร์ / ธีม

เมนู **☰** → **🎨 ฉาก / ตัวละคร / ธีม**

### 8.1 อัปโหลดฉากใหม่
เลือกไฟล์ jpg/png/webp → บันทึกลง `board/assets/scenes/` → การ์ดฉากใหม่ขึ้นในแถบเลือกฉากทันที
(ทุกแท็บที่เปิดอยู่เห็นพร้อมกัน)

### 8.2 อัปโหลดตัวละคร
เลือกไฟล์ png/webp (โปร่งใสจะสวยที่สุด) → ลง `board/assets/characters/` → เลือกเป็น **ตัวละคร** ของ agent ได้เลย

**สไปรท์หลายเฟรม**: ไฟล์ต้องเรียงเฟรมเป็น **แถวเดียวนอน** (เช่น 4 เฟรมกว้างเท่ากัน)
แล้วไปตั้งค่าที่หัวข้อ 8.4 — ค่าเริ่มต้นของไฟล์ที่อัปโหลดใหม่คือ 1 เฟรม (ยืนนิ่ง)

### 8.3 เฟอนิเจอร์ / ของตกแต่ง
อัปโหลดรูปโปร่งใสในช่องเฟอนิเจอร์ → ของจะวางบนฉาก ปรับ **x / y / ขนาด** ต่อชิ้นได้ และกด **ลบ** ออกได้
ของจะอยู่ระหว่างฉากหลังกับตัวละคร (ไม่บังหน้าตัวละคร)

### 8.4 ปรับขนาดและอนิเมชัน
| ตัวปรับ | ผล |
|---|---|
| **ขนาดตัวละคร** (0.5–2×) | ย่อ/ขยายตัวละครทุกตัวบนฉาก |
| **ขนาดตัวอักษรแชท** (11–22px) | ขนาดตัวอักษรในบับเบิ้ลแชท |
| **สีเน้น (accent)** | สีชิปฉากที่เลือก ชื่อ agent ที่โฟกัส |
| **เฟรม / fps ของแต่ละตัวละคร** | จำนวนเฟรมในสไปรท์ชีต และความเร็วการเดิน |

ตัวละครจะเล่นอนิเมชัน **เฉพาะตอนเดิน** และ **หันตามทิศทาง** (ซ้าย/ขวา) — ยืนนิ่งจะโชว์เฟรมแรก

### 8.5 โมเดล 3D (.glb)

ช่อง **เฟอนิเจอร์ / ของตกแต่ง** รับไฟล์ `.glb` (glTF 2.0, ไม่เกิน 12 MB) ได้ด้วย
โมเดลจะถูกเรนเดอร์เป็น 3D จริงบนฉากด้วย three.js ที่ฝังมาในบอร์ด (`board/vendor/three/`)
จึงทำงานได้แม้ไม่มีเน็ต — ไม่เรียก CDN

1. เลือกไฟล์ `.glb` ในช่องเฟอนิเจอร์ → โมเดลจะหมุนช้า ๆ อยู่บนฉาก
2. ปรับ **x / y / ขนาด** จากแถวของมันในสตูดิโอ (ขนาด = ความกว้างเป็น px, สูงคิดเป็น 1.35 เท่า)
3. กด **ลบ** เพื่อเอาออกจากฉาก (ตัว renderer ถูกคืนหน่วยความจำให้อัตโนมัติ)

ข้อควรรู้:
- 1 โมเดล = 1 WebGL context — วางพร้อมกันหลายชิ้นได้ แต่ 5–10 ชิ้นขึ้นไปจะเริ่มกินแรงเครื่องมือถือ
- โมเดลที่มาพร้อม animation ในตัวจะถูกเล่นเฉพาะท่าเริ่มต้น (ยังไม่รองรับการสั่งเล่นอนิเมชัน)
- ใช้เป็น **ของตกแต่ง/ props** เท่านั้น ยังไม่ใช้แทนสไปรท์ตัวละครที่เดินได้
- ถ้าโหลดไม่สำเร็จจะขึ้นว่า `3D โหลดไม่สำเร็จ` ใต้โมเดล (มักเกิดจากไฟล์เสียหรือนามสกุลไม่ใช่ `.glb` จริง)

ข้อมูลที่เก็บ: `data/office-ui.json` (ธีม/ขนาด/เฟรม/ของตกแต่ง) และไฟล์ภาพใน `board/assets/`

## 9. Extensions: skills / plugins / MCP

- **skills** — โฟลเดอร์ `extensions/skills/<ชื่อ>/SKILL.md` เนื้อหาจะถูกฉีดเข้า system prompt
- **plugins** — โมดูล JS ที่เพิ่ม tool เอง (`extensions/plugins/<ชื่อ>/`)
- **MCP** — ต่อ tool จาก ecosystem MCP (`extensions/mcp.json`)
- **clawhub** — registry ให้ติดตั้งจากระยะไกล

สั่งผ่าน CLI: `npm run extensions -- search <คำ>` / `install <ชื่อ>` / `remove <ชื่อ>`

ให้ agent ติดตั้งเองได้ด้วย tool `extensions` (ต้องอนุญาตใน allow list) — ค่าเริ่มต้น `EXTENSIONS_AGENT_WRITES=confirm`
คือทุกคำขอจะเข้าคิว **รออนุมัติ** ที่บอร์ด (ปุ่มในเมนู) หรือตอบ `approve <id>` ใน Telegram/LINE

รายละเอียดเชิงลึก (โครงสร้าง plugin, ตัวอย่างการเขียน tool) อยู่ใน `README.md`

## 10. สร้างภาพ / สร้างวิดีโอ

เปิดใช้ด้วย env (แชร์คีย์กับ chat ได้):

```bash
# ภาพ — endpoint แบบ OpenAI images/generations
IMAGE_API_KEY=...
IMAGE_BASE_URL=https://ark.ap-southeast.bytepluses.com/api/v3
IMAGE_MODEL=seedream-5-0-260128
IMAGE_SIZE=2048x2048

# วิดีโอ — API แบบ async task (POST tasks แล้ว poll)
VIDEO_BASE_URL=https://ark.ap-southeast.bytepluses.com/api/v3
VIDEO_MODEL=seedance-1-0-pro-250528
VIDEO_RESOLUTION=720p
VIDEO_RATIO=16:9
VIDEO_DURATION=5
```

หลังรีสตาร์ท tool `image_generate` และ `video_generate` จะโผล่ในรายการ tool ของ agent
(ต้องติ๊กอนุญาตให้ agent ตัวนั้นด้วย) แล้วสั่งในแชทได้ เช่น
*"สร้างภาพแมวส้มนอนบนโต๊ะไม้ แสงตอนบ่าย"* / *"ทำวิดีโอ 5 วิ เรือกระดาษลอยในถนนฝนตก"*

ผลลัพธ์: `data/images/*.jpg` และ `data/videos/*.mp4` (path จะถูกส่งกลับมาในแชท)

## 11. API และ protocol ย่อ

ทุก request ต้องมี `?token=` หรือ header `Authorization: Bearer <token>`

| endpoint | ใช้ทำอะไร |
|---|---|
| `GET /api/health` | เช็กว่า gateway ยังอยู่ |
| `GET /api/status` | รายการ tool, model, ส่วนขยาย, จำนวนผู้อนุมัติ |
| `POST /api/assets?kind=scenes\|characters\|props&name=<ไฟล์>` | อัปโหลดภาพ/glb (raw body, ≤12MB) |
| `WS /ws?token=` | ช่องทางหลักของบอร์ด (`agents.state`, `office.move`, `ui.update`, ...) |

## 12. แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| เปิดบอร์ดแล้ว `401 unauthorized` | URL ไม่มี `?token=` หรือ token ไม่ตรงกับ `.env` (รีสตาร์ทหลังแก้ `.env`) |
| `npm install` เตือน `install-scripts … not covered by allowScripts` | npm 12 บล็อกสคริปต์ของ dependency โดยค่าเริ่มต้น (ปกติ ไม่กระทบการรัน) — รีโปนี้ประกาศ `allowScripts: { esbuild: true }` ไว้ใน `package.json` แล้ว ถ้ายังเห็นข้อความเดิม ให้ `npm install` อีกครั้ง หรือ `npm install-scripts approve esbuild` (npm 12) / `npm approve-scripts esbuild` (npm 11.16+) ตามด้วย `npm rebuild esbuild` |
| `EADDRINUSE` ตอน start | พอร์ตชน — เปลี่ยน `PORT` หรือปิด process เก่า (`lsof -ti :8787`) |
| รายการโมเดลว่าง | ยังไม่ได้ใส่ key หรือ `*_MODELS` ว่าง → `npm run models` ดูสาเหตุ |
| agent ไม่ยอมใช้ tool | ยังไม่ติ๊กอนุญาตในหน้าการ์ด agent หรือปลั๊กอินชุดนั้นยังไม่เปิด |
| สไปรท์ยืนนิ่ง | ไฟล์อัปโหลดใหม่ = 1 เฟรม → ไปตั้ง **เฟรม/fps** ในสตูดิโอให้ตรงกับชีต |
| เดินแล้วไม่ขยับ/ค้าง | แท็บอยู่เบื้องหลัง (เบราว์เซอร์หยุด animation) — สลับกลับมาที่แท็บนั้น |
| อัปโหลดภาพไม่ขึ้น | นามสกุลไม่รองรับ (รับ svg/png/webp/jpg/gif/avif, และ glb เฉพาะเฟอนิเจอร์) หรือไฟล์เกิน 12MB |
| ของตกแต่งไม่โผล่ | ค่า x/y อยู่นอกจอ หรือยังไม่ได้กดอัปโหลดในช่องเฟอนิเจอร์ (ไฟล์ที่วางในโฟลเดอร์เฉย ๆ ไม่ถูกเพิ่มเป็นของตกแต่ง) |
